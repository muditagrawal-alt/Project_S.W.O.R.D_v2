# Persistent Video Tracking Outputs

This directory stores run artifacts generated by the **Persistent Video Tracking** pipeline.

Each executed video generates an isolated subdirectory named after the video stem (`outputs/<video_stem>/`) containing standardized artifacts:

```
outputs/<video_stem>/
├── tracking/
│   └── tracks.csv                         # Unified frame observations (weapons & persons)
├── trajectories/
│   └── trajectory_segments.csv            # Continuous trajectory segments partitioned on gap > 1
├── kinematics/
│   └── kinematics_observations.csv        # Speed, velocity, acceleration (px/s, px/s²), 8-way compass
├── zones/
│   ├── zone_events.csv                    # Chronological zone entry, exit, and transition events
│   └── dwell_episodes.csv                 # Dwell duration episodes (zone-based & localized stationary)
├── associations/
│   └── person_weapon_associations.csv     # Spatio-temporal person-weapon proximity linkages
├── reports/
│   ├── run_metadata.json                  # Machine-readable provenance (models, configs, environment)
│   ├── run_summary.json                   # Aggregate tracking, kinematics, and execution throughput metrics
│   └── <video_stem>_kinematics_timeline.png # High-resolution speed & acceleration time-series plot
└── annotated_videos/
    └── <video_stem>_tracked.mp4           # Rendered video with HUD, bounding boxes, footpoints, and trails
```

## Output Schemas

### 1. `tracking/tracks.csv`
- `video_name`: Source video filename
- `frame_id`: 0-indexed video frame counter
- `timestamp_seconds`: Video elapsed time in seconds
- `object_type`: Object stream (`weapon` or `person`)
- `track_id`: Integer ByteTrack identifier (separate namespaces)
- `class`: Smoothed class label (e.g. `Pistol`, `knife`, `person`)
- `confidence`: Detection confidence score [0..1]
- `x1`, `y1`, `x2`, `y2`: Bounding box coordinates in pixels
- `center_x`, `center_y`: Bounding box 2D image centroid
- `bottom_center_x`, `bottom_center_y`: Ground footpoint (anchor for persons)

### 2. `trajectories/trajectory_segments.csv`
- `segment_id`: Unique identifier formatted `<video>_<type>_<id>_seg_<idx>`
- `observations_count`: Number of consecutive continuous observations ($N$)
- `start_frame`, `end_frame`: Span of the continuous segment
- `duration_seconds`: Temporal span in seconds
- `is_valid_motion`: Flag ($N \ge 5$) ensuring sufficient temporal depth
- `total_path_length_px`: Cumulative Euclidean distance in pixels
- `displacement_px`: Net Euclidean distance between start and end

### 3. `kinematics/kinematics_observations.csv`
- `from_frame`, `to_frame`: Consecutive observation interval ($\Delta f = 1$)
- `dt_s`: Actual temporal delta ($1 / \text{FPS}$)
- `dx_px`, `dy_px`: Image displacement vector (+X right, +Y down)
- `vx_px_s`, `vy_px_s`: Directional velocity components in px/s
- `speed_px_s`: Scalar speed magnitude in px/s
- `is_stationary`: Boolean flag for speed $\le 15.0\text{ px/s}$
- `heading_deg`: Image heading angle [0..360°)
- `direction_8way`: 8-way compass sector (`N`, `NE`, `E`, `SE`, `S`, `SW`, `W`, `NW`, or `STATIONARY`)
- `ax_px_s2`, `ay_px_s2`, `acceleration_px_s2`: Second-order finite differences in $\text{px/s}^2$ ($N-2$ steps)

### 4. `zones/zone_events.csv` & `zones/dwell_episodes.csv`
- `event`: Event type (`ZONE_ENTRY`, `ZONE_EXIT`, `ZONE_TRANSITION`)
- `from_zone`, `to_zone`: Monitored zone identifiers
- `dwell_seconds`: Non-negative dwell duration ($\ge 0$)
- `dwell_type`: `ZONE_BASED` or `LOCALIZED_STATIONARY`

### 5. `associations/person_weapon_associations.csv`
- `weapon_track_id`: Integer weapon track identifier
- `person_track_id`: Associated person track identifier (or `-1` if unassociated)
- `association_score`: Fused overlap and proximity confidence score [0..1]
- `association_status`: `ASSOCIATED` or `UNASSOCIATED`
- `association_method`: `SPATIAL_IOW_PROXIMITY_TEMPORAL`
- `iow`: Intersection over Weapon area ratio [0..1]
- `distance_px`: Centroid Euclidean distance in pixels
